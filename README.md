# Awesome Code World Model

[![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> This repository **only includes works where a coding agent (or an LLM writing code) builds the world model as executable code** — the program holds the world's state, rules and dynamics, and running it predicts what happens next. In general, we do **not** list purely neural world models or works that only predict the output of existing code.
