# Contributing

Pull requests are welcome. This list only includes works where a coding agent (or an LLM writing
code) builds the world model as executable code. Purely neural world models and works that only
predict the output of existing code are out of scope.

Add the paper under its year, newest first, in this format:

```markdown
**Paper Title** | *Mon YYYY*  
Author One, Author Two, Author Three  
📄 [Paper](https://arxiv.org/abs/XXXX.XXXXX) | 💻 [Project](...) | 💻 [Code](...)
```

Only link pages that exist and are public.
